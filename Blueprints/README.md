# Blueprints

Confirmed designs: the renders, plans and reference photos the game is built from. Every set the owner confirms goes
here, one folder per subject.

| Folder | What it holds |
|---|---|
| `Hangars/Renders/` | Overview of the four hangar sizes (S, M, L, XL) from outside and cut away, and the crew annex's two floors |
| `Hangars/Reference/` | The owner's anchor photos of the real hangar (hall, doors, outside, lobby, kitchen, corridor, lounge, store) and the brief |
| `ATC-Tower/` | Artist renders of the ATC tower and its blueprint (heights and widths) |
| `Airport-Layout/` | Top-down ground layout of the airport, with the tower at location A |
| `Vehicles/Ops-Van/` | Renders of the operations van |
| `Vehicles/SUV/` | Renders of the SUV |
| `Car-Rental/` | Renders of the car-rental building and its wing layout |
| `Terminal-Ceiling/` | The terminal ceiling designs |

Never add aircraft, helicopters or people to the hangar art.

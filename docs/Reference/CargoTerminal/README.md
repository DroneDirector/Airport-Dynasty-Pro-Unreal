# Cargo terminal reference photos

Look references only (owner's reference-photos rule): our own model is built from them, nothing is copied.
All from Wikimedia Commons under free licences (CC0 / public domain / CC BY / CC BY-SA); licence and author of each file below.
Fetched with the Commons API search on 2026-11-22 (scratch script; sources.json is the machine-readable list).

What was taken from them for our model: light grey/white sandwich-panel cladding with horizontal joints and one coloured band, a darker standing-seam roof, high amber/grey sectional doors on the airside under a long canopy with ULD roller decks in front, truck docks on the landside with black dock shelters, rubber bumpers and steel levellers, inside a pale sealed concrete floor with yellow lane lines, grey steel columns and roof trusses, LED high-bay fittings, orange/blue pallet racks and tall grey ETV racks, white insulated cold-room panels with sliding doors, and a glazed office block with dark mullions.

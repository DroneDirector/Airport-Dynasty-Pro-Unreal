# Airport Dynasty Pro (Unreal) 0.17.5

- The fire trucks' lamps can now be adjusted without a new version of the game: every lamp's brightness, colour, beam width and reach, and the indicators' and blue lights' rhythm are in a plain text file, AirportDynastyPro\Content\Settings\TruckLamps.ini in the game folder. Change a number in Notepad, save, restart the game. (A missing file or line falls back to the game's own values.)

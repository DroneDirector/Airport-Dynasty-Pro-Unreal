# Airport Dynasty Pro (Unreal) 0.14.2

- The game's content is now split into separate files, one per building: the terminal (with the lounge and gate seats), the jetways, the car rental, the site, the aircraft, plus one for all materials and textures and one for pieces several buildings share. From now on an update replaces only the files of what changed (a change to one building updates only that building's file). This update itself is a little bigger, as every file is new.
- Nothing looks or plays differently.

# Airport Dynasty Pro 0.1.3

- **Exit**, beside the gear in the top right corner. One click shuts the game down completely and takes you back to
  the home screen or desktop.
  - On Android the game closes and leaves the recent apps.
  - On the PC the window closes and the program quits.
- Exit gives all the game's memory back: the 3D view, its pictures and models on the graphics chip, and the music
  are released before the game closes.

# 0.3.72

## Compressed textures
- New in Settings → Graphics: Compressed textures. The jetways', rotundas' and runway's pictures stay compressed on the graphics chip. They take about a quarter of the memory (the jetway bellows go from about 85 MB to about 21 MB) and are quicker to read. They are very slightly softer.
- On by default on phones and tablets, off on the PC. If a compressed picture can't be loaded, the original is used, so nothing is ever left blank. The decoder comes with the app, so nothing is downloaded.
- Applies when the airport is reopened.

## Which settings apply when
- Every graphics setting now says under it if it doesn't apply straight away:
  - Switching MSAA anti-aliasing on or off applies after restarting the game, the same as the graphics engine (WebGPU).
  - Shadows, the mirror, reflections, glow of lights, bloom, ambient occlusion, sharpen, brightness and the volumetric clouds apply at once everywhere except the airport. There they apply when the airport is reopened, which the settings now say.
  - Resolution, automatic resolution, the frame rate limit and the meters apply at once everywhere.

# 0.3.64

## Phones and tablets: height fog off by default
- Height fog draws the whole place a second time every frame to measure distances, which roughly doubles the work on a phone or tablet. It is now off by default on phones and tablets in every preset, and switched off once on the ones that already have the game. You can turn it on again in Settings → Graphics → Height fog, and it stays on.
- On the PC nothing changes: it stays on from Medium up.

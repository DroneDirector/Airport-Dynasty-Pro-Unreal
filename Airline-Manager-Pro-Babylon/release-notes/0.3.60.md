# 0.3.60

## Smoother airport, same look (phone and PC)
- **Static things merged:** the terminal's static things that share a material and stand in the same area are drawn as one. In the test airport that is about 350 fewer draw calls (2,736 down to 2,382). Nothing that moves, opens, lights up, can be swapped for your own model, or is a rental car is merged.
- **Materials frozen:** materials that never change after loading are no longer re-checked every frame. Lamps, beacons, signs, screens, the ground, wet surfaces, snow and the weather stay live.
- **No first-look stutter:** the graphics are prepared while the airport loads ("Preparing the graphics…"), not the first time something comes into view.
- **No memory clean-up hiccups:** the walking loop no longer creates new objects every frame.
- **On foot:** the picture is no longer cleared before every frame, since the sky and the ground always fill it.

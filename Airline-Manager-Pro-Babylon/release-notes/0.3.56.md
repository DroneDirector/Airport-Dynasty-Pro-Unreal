# 0.3.56

## WebGPU on the PC (try it)
- New in Settings → Graphics: **Graphics engine: WebGL / WebGPU** (PC only, applies after restarting the game). WebGPU takes far less of the processor for each thing drawn, which helps most where the processor is the limit (high draw calls).
- It's off by default: WebGL stays exactly as before. The game's own shaders (the ground, wet surfaces, snow, sun glint, the sky) are kept and translated for WebGPU as they load.
- If WebGPU can't start on a PC, the game uses WebGL by itself and the reason goes to the log (Settings → Updates and errors).

## Fixes
- **Middle mouse button:** pressing the wheel again now takes the mouse back for looking round. If the PC still refuses, a note says so and one click in the game takes it back.

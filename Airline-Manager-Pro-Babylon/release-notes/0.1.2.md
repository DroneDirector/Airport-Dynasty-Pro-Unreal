# Airport Dynasty Pro 0.1.2

- **A performance overlay** in the top left corner. Each part switches on or off on its own under Settings → Graphics:
  - **Frame rate**: frames a second and the time between them.
  - **CPU load**: how much of each frame the processor is busy (% and ms), with a bar that turns yellow, then red,
    as it fills.
  - **GPU load**: how long the graphics chip takes to draw a frame (% and ms), measured by the chip itself, plus
    the draw calls and triangles. Some phones don't report GPU time; on those it says so instead of guessing.
  - **Memory**: the app's memory (RAM, where the device reports it) and roughly what its pictures and models take
    on the graphics chip (VRAM).

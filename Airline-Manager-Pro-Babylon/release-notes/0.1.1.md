# Airport Dynasty Pro 0.1.1

- **A PC installer**: AirlineManagerProBabylon-PC-Setup-0.1.1.exe.
  - It installs into its own folder, with its own Start menu entry, an optional desktop shortcut and its own entry
    in Windows' Apps list.
  - It installs beside the main game's PC app and never touches it. A newer version installs over this one and
    keeps your settings.
  - The zip is still there if you'd rather run it from a folder.
- **A new app icon**, so you can tell this edition from the main game at a glance: a neon cube with a white
  airliner climbing across it, on deep violet. It's on Android and on the PC.
- PC: your settings are now kept between starts.
- The Android app installs beside the main game as before (its own app).

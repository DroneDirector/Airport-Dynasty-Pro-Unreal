# 0.3.82

## Reflections: Both, and the jetways' windows as their own switch
- Reflections (Settings → Graphics) now has a fourth choice: Both. Live and Screen reflections together, for PCs strong enough. Each keeps its own quality slider.
- Jetway windows live: a new switch under Live (and Both). The jetways' windows mirror the apron all round, which is the heaviest part of live reflections. Switching it on or off leaves the terminal's glass as it is. It is off by default on phones and tablets and on by default on the PC.

# Airport Dynasty Pro 0.3.2

**Fixed:** Continue game, New game, Load game, Save game and UI didn't open. The game showed "could not start" with
"THREE is not defined".

- **The cause:** a part of the old 3D cabin's lighting still needed the old 3D engine, which isn't in the Babylon.js
  edition. It ran as soon as the game started, so the whole interface stopped loading.
- **The fix:** it is now only set up where that engine exists. Everything else that runs at start-up has been checked
  for the same problem, and nothing else needs the old engine.

# Airport Dynasty Pro 0.2.1

**Updates from inside the game**: Settings (the gear) → **Updates**.

- See your installed version and whether a newer one is out, and check at any time. The game also checks by itself
  every few hours and tells you when an update is ready.
- **See what the update holds** before installing: its release notes, right there.
- **Install it with one tap.**
  - On Android the update downloads and installs over this version, keeping your settings. Android asks once for
    permission to install updates; the game takes you to that setting.
  - On the PC the game downloads the new installer, closes, installs it quietly over itself and opens again.

**What's new**: Settings → **What's new** shows the three newest updates.

- The newest is open, and the two before it are folded until tapped.
- After each update it also opens once by itself.

**Note:** this is the first version with the updater. Install it by hand once; from now on, updates install from
inside the game.

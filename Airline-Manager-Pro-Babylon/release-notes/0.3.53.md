# 0.3.53

## Fixes
- **Your airport opens again.** Since 0.3.50 it stopped with "This place could not be opened on this device": setting up the wet ground and snow on the roads and the landscape went wrong while the airport was loading.

## Problems go to the log
- If a 3D place can't be opened, the reason and its details now go to the log (Settings → Updates and errors), so they can be looked into.
- If a place is still loading after two minutes, that goes to the log too, with how far it got.

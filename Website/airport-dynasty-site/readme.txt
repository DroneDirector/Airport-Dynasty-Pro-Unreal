=== Airport Dynasty Pro Website ===
Requires Plugins: elementor
Requires at least: 6.0
Requires PHP: 7.4
License: GPL-2.0-or-later

The Airport Dynasty Pro website for Elementor: the game's showcase page with its own look, a
launch-day email list and a WooCommerce buy button.

== Install ==
1. Install and activate the free Elementor plugin (and WooCommerce, for selling the game).
2. Plugins → Add New → Upload Plugin → airport-dynasty-site.zip → Install → Activate.
3. The page "Airport Dynasty Pro" is created and becomes the site's front page (only if the site
   was still showing the latest posts there). See Settings → Airport Dynasty Pro website.

== Editing ==
* Open the page with "Edit with Elementor". Every section is an Airport Dynasty widget (left panel,
  category "Airport Dynasty Pro"): click it to change its texts, pictures and links.
* New pictures (new buildings, new features): click the section, change or add a picture in the
  left panel. The carousel at the top and the "A look inside" pictures take any number of pictures.
* Trailer: click the trailer section and paste the YouTube or Vimeo link.
* Selling the game: create the game as a WooCommerce product (Virtual, Downloadable), then put its
  product ID in Settings → Airport Dynasty Pro website. Every buy button then shows the price and
  goes straight to checkout. Until then they say "Coming soon" and lead to the email list.
* Lists of features and buildings end with “…and much more”: keep that line last when you edit them.
* Preview outside WordPress: php tools/preview.php (writes preview/index.html).
* Launch-day email list: the addresses people leave are listed in Settings → Airport Dynasty Pro
  website, ready to copy.
* Social links, copyright name and the glowing pointer: Settings → Airport Dynasty Pro website.
* The copyright year updates by itself ([airport_dynasty_year] shortcode, also usable anywhere).
